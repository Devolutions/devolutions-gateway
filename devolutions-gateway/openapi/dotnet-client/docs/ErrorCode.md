# Devolutions.Gateway.Client.Model.ErrorCode
Machine-readable reason for a rejected request.  New codes can be added, but existing codes are never renamed or removed. Clients must treat unknown codes as generic failures.  - `bad_request`: The request is invalid. - `unauthorized`: The request is not authenticated. - `forbidden`: The request is not allowed. - `not_found`: The resource doesn't exist. - `request_timeout`: The request took too long to complete. - `conflict`: The request conflicts with the current state of the resource. - `payload_too_large`: The request is too large. - `internal_error`: The Gateway failed to process the request. - `bad_gateway`: The Gateway received an invalid response from an upstream server. - `service_unavailable`: The service is temporarily unavailable. - `gateway_timeout`: An upstream server didn't respond in time. - `insufficient_storage`: The Gateway is out of storage space. - `missing_token`: No token was found in the `Authorization` header or in the `token` query parameter. - `malformed_token`: The token can't be decoded or decrypted, or its claims don't match the schema expected for its type. - `bad_signature`: The token signature doesn't match the provisioner key of the Gateway. - `unknown_subkey`: The token refers to a key ID (`kid`) that doesn't match the sub provisioner key of the Gateway. - `expired`: The token has expired (`exp` claim); the clocks of the token issuer and of the Gateway may be out of sync. - `not_yet_valid`: The token is not valid yet (`nbf` claim); the clocks of the token issuer and of the Gateway may be out of sync. - `gateway_id_mismatch`: The token is restricted to another Gateway ID (`jet_gw_id` claim). - `revoked`: The token contains a value revoked by the JSON Revocation List (JRL) of the Gateway. - `unexpected_replay`: The token was already used, and can't be used again in this context. - `invalid_token`: The token is rejected for a reason not covered by another code. - `wrong_token_type`: The type of the token is not accepted by this route. - `insufficient_scope`: The scope of the token doesn't grant access to this route.
